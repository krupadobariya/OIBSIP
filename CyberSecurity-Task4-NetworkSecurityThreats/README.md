# Common Network Security Threats

## Project Overview

This project presents a research report on common network security threats and their impact on modern computer networks. It explains how different attacks work, their real-world consequences, and practical mitigation strategies to improve network security.

---

## Objective

The objective of this task is to study common network security threats, understand their attack methods, analyse their impact using real-world examples, and recommend effective mitigation techniques.

---

## Topics Covered

- Denial of Service (DoS) and Distributed Denial of Service (DDoS)
- Man-in-the-Middle (MITM) Attacks
- IP Spoofing
- DNS Poisoning (Bonus)
- Threat Comparison
- Security Recommendations
