# Network Security Threats Report

## Introduction

Network security threats are attacks that can harm computers, networks, or data. Understanding these threats helps protect systems from unauthorized access and cyber attacks.

---

## 1. Malware

### Description
Malware is malicious software designed to damage or gain unauthorized access to a computer system.

### Examples
- Virus
- Worm
- Trojan Horse
- Ransomware

### Prevention
- Install antivirus software.
- Keep the operating system updated.
- Avoid downloading files from unknown sources.

---

## 2. Phishing

### Description
Phishing is a cyber attack in which attackers trick users into revealing personal information through fake emails, messages, or websites.

### Prevention
- Verify the sender before clicking links.
- Do not share passwords or OTPs.
- Use two-factor authentication (2FA).

---

## 3. Denial of Service (DoS/DDoS)

### Description
A DoS or DDoS attack floods a server or network with excessive traffic, making it unavailable to legitimate users.

### Prevention
- Use firewalls.
- Use DDoS protection services.
- Monitor network traffic regularly.

---

## 4. Man-in-the-Middle (MITM) Attack

### Description
In a MITM attack, the attacker secretly intercepts communication between two users.

### Prevention
- Use HTTPS websites.
- Avoid public Wi-Fi for sensitive work.
- Use a VPN when necessary.

---

## 5. SQL Injection

### Description
SQL Injection is an attack where malicious SQL commands are inserted into input fields to access or modify a database.

### Prevention
- Validate user input.
- Use parameterized queries.
- Keep applications updated.

---

## 6. Password Attacks

### Description
Attackers try to guess or steal passwords using techniques such as brute force or dictionary attacks.

### Prevention
- Use strong passwords.
- Enable two-factor authentication.
- Change passwords regularly.

---

## Conclusion

Network security threats can cause data loss, financial damage, and unauthorized access. By following good security practices such as using strong passwords, updating software, and staying alert against phishing attacks, these threats can be reduced.
